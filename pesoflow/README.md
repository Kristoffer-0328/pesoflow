# PesoFlow

## Description

PesoFlow is a personal finance management app for tracking wallets, balances, income, expenses, transfers, budgets, and spending activity in one place. It provides an overview dashboard with available balance, wallet sources, monthly summaries, budget progress, spending breakdowns, and recent transactions. Budgets can be started from a 50/30/20 savings template, a one-time trip plan, or a monthly work-expense plan.
